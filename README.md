# 天秤将棋GUI

一方が両方の玉を置き、もう一方が好きな方を持つ。先手番の得を、先手玉の薄さで釣り合わせる将棋のアプリ。
現在対応しているのはWindowsのみです。

## インストール＆セットアップ

1. [Releases](https://github.com/kotenbu135/tenbin-shogi-desktop/releases/latest) から
   `tenbin-shogi-gui_x.y.z_x64-setup.exe` を落として実行します。
2. 「**Windows によって PC が保護されました**」が出たら「詳細情報」→「実行」。
   有料の署名を付けていないため、初回だけこの画面が出ます。
3. 初めて開くと「はじめに」が出るので、**「エンジンを自動で入れる」を 1 回押します**。
   やねうら王＋水匠5（約 40MB）を公式の配布先から取得して、 PC に合うファイルを自動で登録します。
   GPU で読ませたい人は、その下の「GPU で読むエンジンを入れる」（dlshogi with GCT・約 67MB）も押せます
   （[GPU で読むエンジン](#gpu-で読むエンジンdlshogiふかうら王)）。

布石の評価はアプリの中に入っているので、エンジンが無くても布石の検討と AI との対局はできます。
41手目からの本将棋にだけエンジンが要ります。

### 0.3.0 以前から更新する方へ

0.4.0 でアプリの名前を「天秤将棋」から「天秤将棋GUI」に変えました。Windows は名前で別のアプリと
見なすため、**0.4.0 以降は古い版を上書きせず、隣に入ります**。古いショートカットは古い版を指したままなので、
そのまま使うと「新しい版があります」が毎回出ます。一度だけ次の片づけをしてください。

1. 「設定 → アプリ」から **「天秤将棋」**（GUI が付かないほう）をアンインストールする。
   このとき **「アプリケーションデータを削除する」にチェックを入れない**
   （設定とエンジンの登録は新しい版と同じ場所を使っているので、消すと登録し直しになります）
2. スタートメニューの **「天秤将棋GUI」** から開く。タスクバーに留めていたら、留め直す
3. 「はじめに」の右上が **版 0.4.0 以降**になっていれば片づけ完了です

## 使い方

- **新しい対局** … ルール（天秤将棋 / 布石将棋 / 本将棋）と、どちらを人が持つかを選びます。
  段階ごとに担当を分けられます（布石は自分で置いて、41手目からはエンジンに任せる、など）。
- **二飛香（にひきょう）** … 天秤将棋の布石（3〜40手目）の禁じ手です（2026-09-13 に加わりました）。
  飛と香は自陣の同じ筋に合わせて 1 枚までしか打てず、すでに自分の飛か香がある筋に飛・香を打つ手は反則です。
  数えるのは自分の駒だけで、40 手目の制限と一緒に掛かります。**布石将棋は変わりません。**
  二飛香の前に指された天秤将棋の棋譜は、開くと旧ルールで並べ直し、そう知らせます（表題も「二飛香を加える前のルール」になります）。
- **終局** … 詰み・投了・時間切れ・41 手目の裁定に加えて、本将棋の次の 3 つを裁きます。規定は世界コンピュータ将棋選手権の大会ルールに揃えています。
  - **千日手**: 同じ局面（盤・持ち駒・手番）の 4 回目で引き分け。その間ずっと王手をかけ続けた側は負け（連続王手の千日手）
  - **入玉宣言**（27 点法）: 自分の手番にツールバーの「入玉宣言」を押します。玉が敵陣三段目以内・王手されていない・敵陣の駒（玉を除く）が 10 枚以上・持ち駒と敵陣の駒で先手 28 点／後手 27 点以上（飛角と竜馬 5 点、他 1 点）なら勝ち、1 つでも欠ければ負けです
  - **手数上限**: 41 手目を 1 手目として数えて 320 手で引き分け（任意局面からは開始局面から数えます）
- **検討** … 押すと対局は止まり、盤の駒は自分で動かせます。変化を並べながら候補手を見られます。
- **グラフ** … 評価値（±2000）と期待勝率（0〜100%）。押すとその局面へ飛びます。
- **棋譜** … KIF の保存と読み込み。書き出す KIF は 41 手目の局面図から始まる普通の形なので**そのまま将棋所や ShogiHome で開けます**。布石 40 手と先後の選択はヘッダタグ（`天秤布石` / `天秤選択`）に入るので、このアプリで開き直せば玉の配置から並べ直せます。[tenbinshogi.com](https://tenbinshogi.com/) の「棋譜をコピー」も同じ形なので、貼り付け（Ctrl+V）で読めます。
- 画面のレイアウトは変更できます。タブを掴んで別の欄へ運べます（欄の見出しを右クリックでひな形）。

### キー操作

| キー | すること |
|---|---|
| ← → / Home End | 棋譜を戻る・進む・最初・最新 |
| Backspace | 待った（1 手戻す） |
| Space | 一時停止・再開 |
| F | 盤面反転 |
| Ctrl+V | 棋譜を貼り付けて開く |
| Ctrl+C | 棋譜を写す |
| Ctrl+N / Ctrl+O / Ctrl+S | 新しい対局 / 開く / 保存 |

## 表示の言葉（日本語 / English）

画面は日本語と英語のどちらでも出せます。初めて起動したときは端末の言語に合わせ、
以後はツールバー右の **English / 日本語** のボタンで切り替えます（覚えるので次からその言葉で開きます）。
切り替えは窓を読み込み直すので、対局中は確かめてから切り替えます。

英語にすると符号も西洋式（`P-76`、`S*45`）になり、盤の段も数字になります。
**KIF は言葉に関わらず日本語のまま**書き出します（将棋所・ShogiHome で開ける書式のため）。

The interface is available in English. It follows your system language on first launch;
after that, use the **English / 日本語** button on the right of the toolbar. Game records are
always written as Japanese KIF so that Shogidokoro and ShogiHome can open them.

## 更新

起動のたびに新しい版を見に行き、見つかったら知らせます。**承諾したときだけ**入れ替えて再起動します。
「はじめに」→「更新を確認」でいつでも確認できます。

## アンインストール

Windows の「設定 → アプリ」から「天秤将棋GUI」を消します。
設定と入れたエンジンは `%APPDATA%\com.fusekishogi.tenbin` に残るので、そこも消せば何も残りません。
設定だけまっさらにしたいときも、このフォルダを消してから起動します。

## エンジンを手動で入れる

「エンジン」→「実行ファイルを選んで追加」か「フォルダから取り込む」。USI 対応なら何本でも登録できます。
起動して `usi` の申告を読み、設定画面を申告どおりに作ります。

- やねうら王: https://github.com/yaneurao/YaneuraOu/releases/tag/V9.00
  （`yaneuraou-V900-git-win64-all.7z` の中の `NNUE_halfkp_256x2_32_32/…_AVX2.exe` が水匠5 用）
- 水匠5 の評価関数: https://github.com/yaneurao/YaneuraOu/releases/tag/suisho5
  （展開した `nn.bin` を実行ファイルの隣の `eval/` へ。勝率の目盛りは **652 / +51**）

エンジンが起動しないときは「エンジン」→「USI ログ」で生のやり取りを見られます。

## 布石の模型を差し替える（世代を並べる）

1〜40 手目の布石は、アプリに同梱した学習済みの模型（方策・両玉の価値表・価値ネット）が指します。
別の世代を試したいときは「エンジン」→ 下の「布石の模型（世代）」→「フォルダを足す…」で、
`models.json` と 3 つの重みが入ったフォルダを足せます。同梱はそのまま残ります。

足した世代は、対局の席（「布石を指すもの」）と検討の欄で選べます。**席ごとに別の世代を置けるので、
世代どうしを指させて見比べられます。** 何が強いかを決めるには数百局の対局が要るので、
1 局の結果で判断しないでください。

両玉の価値表は方策と対（同じ世代）です。世代が食い違うフォルダを足すと、一覧に「両玉の表なし」と出て、
天秤将棋の 1〜2 手目だけが価値ネットに落ちます（布石の 3 手目以降は動きます）。

### GPU で読むエンジン（dlshogi・ふかうら王）

同じ手順で登録できます。申告に `DNN_` の項目があれば **GPU を使うエンジン**として扱い、次の 3 つが変わります。

- **準備を長く待ちます。** 模型を GPU 向けに組み直す（TensorRT）ので、初回は数分〜十数分かかります。
  待つ秒数の既定は 20 分で、「エンジンの設定 → GPU で読むエンジン」で変えられます。
  待っている間の様子（エンジンが出す行）は検討の枠や状態の行に出ます
- **同時に 1 本だけ立ちます。** GPU は 1 枚しかないのが普通で、席の数だけ模型を載せると VRAM が尽きて落ちます。
  検討で空いているものは自動で畳んで譲りますが、対局中や読んでいる最中は譲らずに断ります。
  エンジン同士の対局では、先後で同じ 1 本を使い回します
- **勝率の目盛りは申告から読みます。** dlshogi 系は勝率を `Eval_Coef` 倍して cp にしているので、
  その値をそのまま目盛りの S に使います（当てはめが要りません）

0.4.1 以前に登録したエンジンは、一度「エンジンの設定 → 申告を読む」を押すと GPU として扱われます
（押すまでは以前のまま、待ち時間 2 分・同時に何本でも、で動きます）。

#### 自動で入れる

「はじめに」の **「GPU で読むエンジンを入れる」** を押すと、
[dlshogi with GCT（第31回世界コンピュータ将棋選手権版）](https://github.com/TadaoYamaoka/DeepLearningShogi/releases/tag/wcwc31)
を公式の配布先から取って登録します（約 67MB）。実行ファイル・DLL・モデルが 1 つの書庫に入っているので、
これだけで動きます。**CUDA も TensorRT も要りません**（同梱の DirectML で動くため、
DirectX 12 の GPU なら NVIDIA でなくても構いません）。要るのは Windows 10 1903 以降と
VC++ ランタイムだけです。

書庫には TensorRT 版（`dlshogi_tensorrt.exe`）も入っています。速いですが CUDA 11.1・cuDNN・
TensorRT 7.2.3.4 を別に入れる必要があるので、自動では登録しません。揃っている人は
「エンジン」→「実行ファイルを選んで追加」で登録し、`DNN_Model` に同じ `.onnx` を指してください。

新しい dlshogi（2022 年以降）のモデルは、配布元がライセンスへの同意を求めており、書庫にパスワードが
掛かっています（「このパスワードは他に転記しないでください」）。**自動では入れられません**。
使いたい人は配布元の案内に従って自分で展開し、手で登録してください。

#### 手で入れるとき

模型（`.onnx`）と実行に要る DLL は配布元の説明どおりに揃えてください。
足りないと、エンジンは何も言わずに終了します。そのときは「USI ログ」に終了コードが出ます。

#### 推論の速さ（CUDA / DirectML / CPU）

エンジンが準備（`isready`）のときに `info string … provider cuda|dml|cpu` を出すと（天秤将棋の拡張エンジン Libra が出します）、
何で読んでいるかを「USI ログ」に「推論: DirectML」のように出し、「エンジン」の一覧にも添えます。

Libra の配布物は DirectML 版です。**NVIDIA の GPU の PC で DirectML か CPU のまま読んでいると、
CUDA 版への切り替えを 1 度だけ案内します**（「今後表示しない」で止められます。「エンジン」の一覧からいつでも開けます）。
CUDA 版は RTX 5070 Ti の実測で DirectML の約 4 倍速いです。切り替えは、やねうら王の導入と同じくボタンで進めます。

1. 案内の画面に、CUDA 12・cuDNN 9（CUDA 12 用）・CUDA 版の ONNX Runtime が揃っているかが出ます
2. CUDA 12 か cuDNN 9 が無ければ「足りないインストーラをダウンロード」を押します。NVIDIA の配布元から
   「ダウンロード」フォルダに取ってくる（CUDA 12.9.1 のネットワークインストーラ 16MB、cuDNN 9.26.0 のインストーラ 1.9GB）ので、
   **インストールはご自身で**行い、「確かめ直す」を押します。CUDA は「カスタム（詳細）」で「CUDA」だけを入れれば足ります
   （画面のドライバーは入れ替えません）。NVIDIA のライブラリはこのアプリにもエンジンにも入っていません
3. 揃ったら「CUDA 版に切り替える」を押します。ONNX Runtime 1.30.0 の CUDA 版（約 380MB）を取ってきて、エンジンのフォルダの
   DLL を差し替えます。元の DLL は `*.dml-prev` に残るので、「DirectML 版に戻す」でいつでも戻せます

CUDA 12 と cuDNN 9 を標準の場所（`C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.x` と
`C:\Program Files\NVIDIA\CUDNN\v9.x\bin\12.x\x64`）に入れれば、アプリがエンジンを起動するときに `PATH` の末尾へ足すので、
**環境変数を触る必要も、アプリを開き直す必要もありません**（cuDNN 9 のインストーラは `PATH` に足さないため。
足さないと `cudnn64_9.dll` が見つからず、エンジンは CPU で読みます）。別の場所に入れたときは、案内の「手で入れるとき」を見てください。
切り替えようとして DLL が足りなかったとき（エンジンは止まらずに CPU で読み続けます。DirectML 版より遅くなります）は、
ONNX Runtime のエラー文を出し、足りないものを同じ画面で揃えられます。

2026-09-14 に RTX 5070 Ti・CUDA 12.9・cuDNN 9.26 で、DirectML 版 → 切り替え → `provider cuda` → 戻す → `provider dml` を
アプリと同じ起動の仕方で確かめました（`PATH` を足さずに起動すると `provider cpu` になります）。

### 布石にも対応するエンジン（Libra）で最後まで指す

「布石にも対応」で登録したエンジンは、新しい対局の「本将棋（41手目以降）」の一覧にも出ます。
**布石と本将棋に同じエンジンを選ぶと、1 本のプロセスが 1 手目から終局まで指します**（GPU で読むエンジンでも 1 本で済みます）。
「エンジン」の一覧の「本将棋の既定にする」で、検討の「自動」が 41 手目以降に使うエンジンにもできます。

- **両玉と先後の選択も任せます。** `Fuseki_Mode` を名乗るエンジンの席は、天秤将棋の 1〜2 手目（玉）もエンジンが置きます。
  先後の選択は両玉を置いた局面を読ませ、最善手の勝率（先手の勝率）が 50% 以上なら先手を持ちます。
  名乗らないエンジンの席は、これまでどおりアプリに入っている両玉の表が決めます
- **入玉宣言をさせます。** `Declare_Win` を名乗るエンジンには、エンジンの設定で値を決めていなければ `true` を送ります。
  宣言（`bestmove win`）はアプリが条件を確かめ、満たせば宣言した側の勝ち、欠ければ負けにします

## 開発

Tauri v2 + TypeScript（フレームワーク無し）。ルールは wasm（cppshogi）、本将棋は shogiops。

```bash
npm install
npm test                 # USI の分解・KIF の読み・持ち時間の書式
cargo test -p usi-host   # プロセス管理のテスト
npm run tauri dev        # アプリとして起動
```

push と PR では [ci.yml](.github/workflows/ci.yml) が型・テスト・ビルド・clippy と、
Windows でアプリが通るかを回します。
