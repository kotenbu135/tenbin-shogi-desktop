# 画面の設計

手本は ShogiHome（盤を中央に、右に棋譜と検討、下に評価グラフ、上に大きな操作）。
その骨格を借り、盤と駒は公開版サイトと同じものを使い、天秤将棋にしか無いものを一つだけ目立たせる。

## 盤と駒（慣習）

日本将棋連盟の盤面図、将棋所・ShogiHome と同じ向きで描く。

- 先手が手前（下）。筋は盤の上に 9〜1 の算用数字、段は盤の右に 一〜九 の漢数字
- 後手の駒台は左上（盤の上端に揃える）、先手の駒台は右下（盤の下端に揃える）
- 駒台の並びは 玉 飛 角 金 銀 桂 香 歩。後手は逆順にして、後手から見て同じ並びになる。
  本将棋では玉の枠を消し、歩を2列ぶん使う
- 名札は「☗先手」「☖後手」。塗り＝先手、輪郭＝後手。手番の側に「手番」の札を足す
- 玉将は先手、王将は後手（上位者が王将を持つ慣習）
- マスは実物の盤と同じく縦長（1尺2寸 × 1尺1寸 ≒ 1.09）。星は３四・６四・３七・６七の交点
- 駒の画像は lishogi の kanji_light（Ka-hu, CC BY 4.0）。公開版サイトと同じ。
  後手の駒は回転済みの別ファイルで、CSS では回さない
- 盤の色 #f9b34e と木目の縞、罫線の黒、選択・行き先・直前の手の色は公開版サイトと同じ
- 布石中は手番側の自陣四段を淡く塗る。41手目からは盤の縁の色を墨に変える（ルールが変わったことが見える）

## 符号

日本将棋連盟の表記。shogiops の日本語表記を使う。

- 「７六歩」「同　銀」「２二角成」「５八金左」。「打」は盤上の駒が同じマスへ動けるときだけ
- 布石中は盤上の駒が動けないので「打」は付けない
- 先後の記号は ☗☖（公開版サイトと同じ。連盟の出版物は ▲△）

## 目立たせるもの

**天秤グラフ**。評価値の折れ線の上に天秤の梁を置き、現局面の勝率で傾く。
左の皿が先手（塗り・朱）、右の皿が後手（輪郭・藍）。折れ線の背景は布石（1〜40手）を薄く帯にして、
41手目の境を縦線で示す。目盛りは常に「先手の勝率」で、cp は換算してから載せる。

## 色

| 名 | 値（明） | 値（暗） | 使う所 |
|---|---|---|---|
| 銀鼠 `--bg` | #e6e3dc | #1c1f22 | 地。紙色ではなく灰にして盤の木色を立てる |
| `--panel` | #faf9f5 | #272b2f | 面 |
| 墨 `--ink` | #23262a | #e9e6df | 文字・梁 |
| 盤 `--board` | #f9b34e | 同じ | 盤。明暗で変えない（駒の朱字と成駒の判別が落ちる） |
| 駒台 `--stand` | #d9994c | 同じ | 駒台 |
| 朱 `--sente` | #b93c2c | #d65a48 | 先手の皿・勝率の帯 |
| 藍 `--gote` | #2f4e73 | #6e93c0 | 後手の皿・候補の印・フォーカス |

朱と藍は「天秤の皿」と「検討の帯」にだけ使う。ボタンや見出しには使わない。

## 文字

- 符号・題字・段の漢数字は明朝（ヒラギノ明朝 → 游明朝 → Noto Serif JP）
- 操作と本文はゴシック（ヒラギノ角ゴ → Yu Gothic UI → メイリオ → Noto Sans JP）。数字は等幅（tnum）
- 外部フォントは読まない（オフラインで動くアプリなので）。Linux で開発するときは `fonts-noto-cjk` を入れる

## 配置

```
┌ 天秤将棋  [▶ 新しい対局][▦ 布石将棋][↶ 待った][⚑ 投了]     [USI ログ][エンジン][テーマ] ┐
├───────────────────────────────────────────┬──────────────────────┤
│  ┌後手駒台┐    9 8 7 6 5 4 3 2 1                     │ 対局の見出し・選択         │
│  │       │   ┌─────────────────┐ 一           ├──────────────────────┤
│  └───────┘   │                 │ 二           │ 棋譜  |◀ ◀ ▶ ▶|         │
│  ☖後手       │       盤        │ …            │  開始局面                 │
│              │                 │ 九    ☗先手  │  両玉 / 布石 / 本将棋       │
│              └─────────────────┘   ┌先手駒台┐ ├──────────────────────┤
│                                     └───────┘ │ 検討（エンジン・候補の表）    │
├───────────────────────────────────────────┤                      │
│ 天秤グラフ                                    │                      │
├───────────────────────────────────────────┴──────────────────────┤
│ 状態の一行（いまの局面と、誰が何をする番か）                                     │
└──────────────────────────────────────────────────────────────────┘
```

- マスの幅は使える高さと幅の小さい方から決める（`ResizeObserver` が `--sq` に入れる）
- 棋譜は行を押すとその局面を表示する。← → Home End でも動く。過去の局面では盤を触れず、「この局面から指し直す」で分岐する
- 面は角丸なし。角丸は操作部品の 4px だけ。境は 1px の線と地の色の差で作る。影は盤と駒台だけ
- 文言は利用者の側から。「置く人が、先手陣に先手玉を置きます」のように次にやることを言う

## やらないこと

- 自作の駒画像や記号での代用。駒は将棋の顔で、公開版と同じ駒を使う
- 文字の色替えや太字での強調、全部大文字の見出し
- カードの敷き詰め、装飾のグラデーション
- 読み込み時のアニメーション。動くのは天秤の梁（勝率が変わったとき）と盤の縁の色（41手目）だけ。`prefers-reduced-motion` で止める
