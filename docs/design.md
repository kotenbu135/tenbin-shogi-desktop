# 画面の設計

手本は ShogiHome（盤を中央に、右に棋譜と検討、下に評価グラフ、上に大きな操作）。
その骨格を借りつつ、天秤将棋にしか無いものを一つだけ目立たせる。

## 目立たせるもの

**天秤グラフ**。評価値の折れ線の上に天秤の梁を置き、現局面の勝率で傾く。
左の皿が先手（塗り・朱）、右の皿が後手（輪郭・藍）。折れ線の背景は布石（1〜40手）を薄く帯にして、
41手目の境を縦線で示す。目盛りは常に「先手の勝率」で、cp は換算してから載せる。

## 色

| 名 | 値（明） | 値（暗） | 使う所 |
|---|---|---|---|
| 銀鼠 `--bg` | #e3e0d8 | #1f2327 | 地。紙色ではなく灰にして盤の木色を立てる |
| `--panel` | #faf9f5 | #292e33 | 面 |
| 墨 `--ink` | #23262a | #e9e6df | 文字・梁 |
| 榧 `--board` | #e7cb8f | #d5b97c | 盤 |
| 朱 `--sente` | #b93c2c | #d65a48 | 先手の皿・勝率の帯・成駒の字 |
| 藍 `--gote` | #2f4e73 | #6e93c0 | 後手の皿・行き先の印・フォーカス |

朱と藍は「天秤の皿」と「検討の帯」にだけ使う。ボタンや見出しには使わない。
塗り＝先手、輪郭＝後手の規約は公開版サイトと同じ。

## 文字

- 駒と題字は明朝（Noto Serif JP → 游明朝 → ヒラギノ明朝）。駒は五角形の紙色に墨の楷書、後手は 180 度回す
- 操作と本文はゴシック（Noto Sans JP → Yu Gothic UI → ヒラギノ角ゴ）。数字は等幅（tnum）
- 外部フォントは読まない（オフラインで動くアプリなので）

## 配置

```
┌ 天秤将棋  [新しい対局][布石将棋で始める][待った][投了]      [USI ログ][エンジン][テーマ] ┐
├────────┬─────────────────────────────────┬──────────────────┤
│ 後手駒台 │            盤 9×9                │ 対局の見出し・選択    │
│        │                                   ├──────────────────┤
│        │                                   │ 棋譜（フェーズの見出し）│
│ 先手駒台 │                                   ├──────────────────┤
├────────┴─────────────────────────────────┤ 検討（エンジン・候補表）│
│ 天秤グラフ                                   │                    │
├──────────────────────────────────────────┴──────────────────┤
│ 状態の一行（いまの局面と、誰が何をする番か）                            │
└──────────────────────────────────────────────────────────────┘
```

- 盤の大きさは使える高さと幅の小さい方（`ResizeObserver` が `--board-size` に入れる）
- 面は角丸なし。角丸は操作部品の 4px だけ。影も使わない。境は 1px の線と地の色の差で作る
- 文言は利用者の側から。「玉を置く役が、先手陣に先手玉を置きます」のように次にやることを言う

## やらないこと

- 文字の色替えや太字での強調、全部大文字の見出し
- カードの敷き詰め、装飾のグラデーション
- 読み込み時のアニメーション。動くのは天秤の梁（勝率が変わったとき）だけ。`prefers-reduced-motion` で止める
