# 既存の将棋 GUI の流れと、このソフトの問題点（2026-09-09）

Windows で実機確認できたあと、既存のソフト（ShogiHome・将棋所・ShogiGUI）を人がどう使うかを Web で調べ、
このソフトの問題点を洗った。直したものと、残した提案を分けて書く。

## 人がソフトを使う流れ（3 本に共通）

1. **対局**。対局設定で人かエンジンかと時間を決める。対局中は手番のエンジンの思考（予想手・深さ・NPS・評価値・読み筋）が
   画面の下に出て、評価値グラフが対局者の評価で伸びていく（将棋所「思考情報」、ShogiHome は対局者のエンジンを検討と同じ欄に出す）
2. **終局**。結果が出て棋譜が残る（将棋所は自動保存）。そのまま **棋譜解析** に進む。全手を順に評価してグラフを埋め、悪手に印を付ける
3. **検討**。グラフや棋譜を押して気になる局面へ移り、検討（MultiPV・読み筋・盤の矢印）。読み筋を継ぎ盤で再現し、分岐を棋譜に挿入する
4. 検討は局面を動かしても追従し、「停止／再開／検討終了」で制御する（ShogiHome）。将棋所は Space で開始・停止、Esc で終了

## ShogiHome の UI から取ったこと

- **思考と検討は同じ場所**。`EngineAnalytics` は対局者のエンジンと検討のエンジンを縦に並べる 1 つの欄。見出しにエンジン名・予想手・最善手・NPS・ハッシュ使用率、
  表の列は 時間 / 順位 / 深さ / ノード / 評価 / 読み筋。「思考」タブは履歴、「読み筋」タブは最新だけ
- **評価値グラフ**は対局者（先手・後手）と検討の系列を色で分ける。赤い縦線が現局面。押すとその手数へ移る。評価値（±2000）と期待勝率（0〜100%）の 2 種
- 矢印は上位 3 手（設定で 0〜）。評価値の符号は「先手有利がプラス」に統一できる
- タッチ向けに大きなボタン、盤のレイアウトが選べる、カスタムレイアウト

## 見つかった問題点

| # | 問題 | 既存のソフトでは | 対応 |
|---|---|---|---|
| 1 | 手番でない側の名札が縦に折れる（名前が 1 文字ずつ改行）。駒台の上下の寄せも効いていなかった（CSS が `.stand.gote` を見ていたが要素は `.stand.far`） | 名前の下に時計 | **直した**。名札は 1 行目に印・名前・手番、2 行目に時計。駒台は奥が上・手前が下 |
| 2 | 対局中にグラフが伸びない（検討を始めないと点が乗らない） | 対局者の評価でグラフが伸びる | **直した**。対局中のエンジンの評価を「対局」の系列に。内蔵の布石も候補を出してから手を選ぶ |
| 3 | 終局後に「対局は終わっています」で検討できない | 終局後こそ検討・解析する | **直した**。終局した局面もその段階（布石／本将棋）のルールで検討する。右上に終局の表示と案内 |
| 4 | グラフの左の天秤の図 | 無い | **外した**。現局面の勝率はカーソルの脇に数字で |
| 5 | 「思考」（名札の下の 1 行）と「検討」の役割が重なる | 1 つの欄に対局者と検討のエンジンを並べる | **直した**。対局中は検討パネルの上に「対局の枠」（席ごと）を出し、読み筋・深さ・ノードを検討と同じ表で見せる。指したら止まり読みは残る。矢印は検討の候補だけ（人が相手のとき手を先に見せない） |
| 6 | 棋譜解析が無い。対局のあとの決まった流れが無い | 対局 → 棋譜解析 → 検討 | **追加**。「棋譜解析」で範囲と 1 局面の秒数を決め、布石は内蔵、41 手目からは既定のエンジンで順に評価してグラフの「検討」の系列を埋める。進み具合と「止める」 |
| 7 | グラフを押しても局面へ移れない | 3 本とも押すと移動 | **直した** |
| 8 | 候補表の cp が手番側の符号で、隣の勝率（先手）と符号が食い違う | ShogiHome は「先手有利がプラス」に統一できる | **直した**。表の cp と詰みは先手から見た値に統一 |
| 9 | 過去の局面を見たあと wasm の局面が戻らない（`viewAt(moves.length)` は同期しない）。布石中に過去を見て戻ると手番がずれうる | — | **直した**。`Game.resync()` を足し、読み筋の符号化で別の Game を作ったあとに戻す |
| 10 | 対局の枠の読み筋が、指したあと別の局面の符号で描かれて「—」になる | — | **直した**。読み筋の符号化はその枠の局面（position 行）から作る |
| 11 | 検討の見出しに部品が多く、380px の右列で「検討」の題が縦に折れる | — | **直した**。題と開始ボタンを 1 行目、候補数・枠を足す・棋譜解析を 2 行目に |

## 残した提案（優先順）

1. **読み筋の再現（継ぎ盤）と棋譜への分岐の挿入**。ShogiHome の「▶ 再現」「棋譜に挿入」。検討の中心の操作で、これが無いと読み筋は文字で追うしかない
2. **棋譜解析の結果を棋譜に残す**。評価値の列、悪手・疑問手の印（ShogiGUI の ▲▼）、KIF のコメントに読み筋
3. **対局中の検討の扱い**。ShogiHome も将棋所も対局中は検討を開かない。いまは棋譜解析だけ確認を出す。検討の開始も対局中は確認するか、対局の枠だけにする
4. **検討の「停止／再開」**。エンジンを立てたまま休ませる（起動が重いエンジン向け）。いまは止めると次に起動し直す
5. **ショートカット**。Space で検討の開始／停止、Esc で終了（将棋所）。矢印キーは済み
6. **終局のダイアログと自動保存**。将棋所は対局後に自動保存し「対局結果一覧」から開ける
7. **棋譜コメント・しおり**、局面図の書き出し
8. 見出しの予想手（ponder）・ハッシュ使用率。ハッシュが 90% を超えたら赤（ShogiHome）
9. 評価値の目盛り（±2000）表示は入れない判断。エンジンごとに目盛りが違うので、共通の通貨は勝率だけにする（`docs/plan-model-distribution.md`）
